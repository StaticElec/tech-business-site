# Photos

Drop real photos here using the exact file names below. Until a file exists,
the site shows a labelled "Photo needed" box in its place. Astro resizes and
compresses everything here automatically at build time, so you can use the
original camera files (landscape, at least 1600px wide is ideal).

The paths are set in `src/data/site.ts` — change them there if you'd rather
use different file names or formats (.jpg, .png, .webp all work).

| File                         | Where it appears                   | Shape         |
| ---------------------------- | ---------------------------------- | ------------- |
| `logo.png` (or .svg)         | Header (optional; text otherwise)  | any, ~44px tall |
| `hero-repair.jpg`            | Homepage hero                      | landscape 4:3 |
| `service-laptop-repair.jpg`  | Services: Laptop & Desktop Repair  | landscape 4:3 |
| `service-software.jpg`       | Services: Windows & Software       | landscape 4:3 |
| `service-upgrades.jpg`       | Services: Hardware Upgrades        | landscape 4:3 |
| `service-data-transfer.jpg`  | Services: Data Transfer & Backup   | landscape 4:3 |
| `service-setup.jpg`          | Services: Setup & Optimization     | landscape 4:3 |
| `blog/<post-name>/...`       | Blog article photos                | cover 16:9    |

Photos are cropped to fit their shape, so keep the subject near the centre.
Real photos of your own work only — no stock or AI-generated images.
